### Research software

- **[HumanFilteringToolsComparison](https://github.com/ashwini-forge/HumanFilteringToolsComparison)**: benchmarking human-read filtering tools on paired-end sequencing data; derived from Penn/CHOP's decontam project.
- **[ReadGenerator](https://github.com/ashwini-forge/ReadGenerator)**: generating synthetic paired-end DNA reads from configurable mixtures of human, bacterial, PhiX174, and viral/phage sequences.
- **[MethylAnalyser](https://github.com/ashwini-forge/MethylAnalyser)**: an R pipeline for Infinium HumanMethylation 450K data.

Developed and contributed to these tools within the **Penn/CHOP Microbiome Program**:

- **[PhylogeneticProfiler](https://github.com/PennChopMicrobiomeProgram/PhylogeneticProfiler)**: taxonomic profiling of shotgun metagenomic data.
- **[PathwayAbundanceFinder](https://github.com/PennChopMicrobiomeProgram/PathwayAbundanceFinder)**: pathway-abundance analysis of shotgun metagenomic data.
- **[decontam](https://github.com/PennChopMicrobiomeProgram/decontam)**: host-read filtering.
- **[dnabc](https://github.com/PennChopMicrobiomeProgram/dnabc)**: barcode processing.
- **[illqc](https://github.com/PennChopMicrobiomeProgram/illqc)**: sequencing-read quality control.
- **[ShotgunPipeline](https://github.com/PennChopMicrobiomeProgram/ShotgunPipeline)**: integrated shotgun metagenomics workflows.
